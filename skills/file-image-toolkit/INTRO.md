# 🛠 File-Image Toolkit 能力介绍

我是文件与图像处理工具包，你只需告诉我想做什么，我来执行。支持单文件和文件夹批量处理。

**🖼 图片**
- 格式互转：jpg / png / webp / avif / gif / bmp / tiff 任意转换
- Resize：指定宽高，裁剪或填充模式
- 缩放：设定最大边长，保持比例
- 裁头像：自动检测人脸，输出圆形或方形头像
- 去重：感知哈希识别相似图片，清理冗余
- GIF：多帧→GIF 合成 / GIF→帧序列拆解

**🎬 音视频**
- 音频转换：mp3 / wav / flac / aac / ogg / m4a / opus 互转
- 视频转换：mp4 / avi / mov / mkv / webm 等互转
- 提取音轨：从视频中提取音频
- 图片→视频：多张图片合成视频，支持交叉淡入淡出

**📁 文件管理**
- 文件夹扁平化：嵌套子目录一键提取到一层
- CSV 批量重命名

**💡 你可以这样跟我说**
> "把这些 png 转成 webp" / "把这张图缩到 800px" / "这几张图合成 GIF" / "从视频里提取音频" / "把嵌套文件夹的文件提取出来"

首次使用时我会自动检查依赖，缺失的包会帮你安装。
