# 旅行规划的地基

先定性：**一次旅行是用一段有限的时间去买幸福，交通几乎总是负收益。** 所有取舍都从这个等式推导。

## 两种模式，两套公式

| 模式 | 公式 | 什么时候用 |
|---|---|---|
| 游览（效率优先） | 幸福总量 / 总时间 = （目标地点幸福 + 交通幸福）/ 总时间 | 目的地值得看的东西多、时间紧 |
| 度假（幸福总量优先） | 幸福总量 = 幸福效率 × 总时间 | 主要目的是休息、恢复 |

同一个目的地，选错模式会让整份计划都别扭：游览模式塞不满会焦虑，度假模式排太满会疲惫。

## 规划顺序

顺序本身是方法的一部分——**先锁不可逆的，后定可改的**。

**游览模式**

1. 跨市交通（往返方式）
2. 市内交通
3. 确定天数
4. 确定景点（候选 → 确定）
5. 定酒店
6. 找餐厅 / 商圈
7. 排每日行程

**度假模式**

1. 交通
2. 酒店
3. 候选景点与餐厅
4. 行李清单
5. 完成（可选：排详细行程）

倒着做的典型后果：先挑了景点，再发现交通接不上；先订了酒店，再发现每天要横穿城市。

## 三条判断

1. **目标地点的单位时间幸福收益最高，交通通常是负收益。** 所以「少移动」经常比「多打卡」划算——这条能推翻很多看起来很满的行程表。
2. **度假模式的核心是先最小化不快乐**（住得差、赶路、排队、嘈杂），再谈延长天数。先降噪，再延展。
3. **景点分「候选」和「确定」两阶段。** 候选池先按属性净化（去掉非真实景点这类噪声），再按时间、同行人等约束筛成确定景点。不要一上来就定景点。
