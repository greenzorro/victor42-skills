# 六合解读法

poem-six-lens 工作流 **第一阶段(草稿)与第四阶段(定稿)** 的参考文件。主 SKILL.md 定义"何时做、按什么顺序";本文件定义"具体怎么写这份解读"。

## 六维

| 维度 | 中文 | 回答什么 | 常见失败模式 |
|---|---|---|---|
| **世 时代** | 时代 | 哪个时代塑造了它? | 只取表层时代;或反过来,给所有诗都套"双重时代"(多数山水咏物诗就活在当世,没有古今之分) |
| **人 作者** | 生平 | 谁写的,为什么是他? | 只罗列生平,不解释*为什么偏偏这个人*能写出 |
| **地 地理** | 地理 | 何处,空间如何结构意义? | 当成背景,而非主动的构成力 |
| **统 传统** | 传统 | 它站在哪条脉络上? | 几乎总被忽略——但这正区分了诗与日记 |
| **受 接受史** | 接受史 | 后世如何重读它? | 被忽略——但每一次阅读(包括当下这一次)*都是*这条河里的一脉 |
| **文 作品本体(枢纽)** | 作品本体 | 它为什么是*艺术*,而不只是陈述? | **最大的盲区**——读者从语境直接跳到"意思",跳过了技艺 |

**【文】是枢纽。** 其余五维是流入它的因果支流。读一首诗 = 轮流站在每个维度上,然后退后,看它们如何汇聚。

## 各维度细则

### 【世】时代——分清诗的语境层次

写一首诗的时代语境,可能只在一层,也可能分多层。**先辨认这首诗属于哪种,不要默认套用任何一种:**

- **单层语境**(多数诗:山水、咏物、赠别、田园、应制……):诗所写的就是诗人当世,没有古今之分。把"时代"理解为"诗人身处并从其中写作的世界"即可。
- **双层语境**(咏史、怀古、借古讽今):诗表面写前朝古事(**所咏之世**),实际从作者所处的时代(**写作之世**)出发。两者不同,它们之间的张力往往就是诗的引擎——一个看着自己的朝代重演前朝覆辙的诗人,同时在做两件事。
- **所指与所处之分**(某些寄托诗):诗表面写一件事,实际指向另一件事(不是"古vs今",而是"此事vs彼事")。

**关键:不要把"双重时代"当成所有诗的标准配置。** 多数山水咏物诗就活在它自己的当世,硬给它套"双重时代"是在虚构一个不存在的引擎。该单层就单层——一首诗的"世"是单层的,这本身不是解读的贫弱,而是这首诗的真实属性。

### 【人】作者——回答"为什么偏偏是他?"

不要停在生平(生卒、官职)。关键问题是:**怎样的身份复合体,让这个特定的人成为这种素材的独特反应器?**

找到这个复合体——让此人拥有他人没有的视角的那些身份切面。然后把每个切面对应到它在诗里*启用*了什么。一个在文本里不起作用的切面只是生平;一个能解释某个具体意象为何刺痛、或某个结构选择为何可用,那才是复合体的一部分。

### 【地】地理——主动的构成,而非背景

两种不同用法,适用时都要做到:

**(a) 诗*内*的空间**——意象的空间逻辑。追踪诗眼如何移动:是由远拉近?由公到私?压缩距离还是拉长?空间序列往往镜像或反转道德逻辑——比如一首意象逐帧缩小、而道德重量反而加重的诗,在跑**反比例修辞**,结构本身就是论证。

**(b) 诗*后*的地理**——诗所隐去的真实空间代价。一首设在终点的诗,可能压掉了通往那里的路。这种压掉很少是中性的——它本身就是批判。诗只展示了终点;那条路,连同它的人力物力代价,被有意留给读者去想象。

### 【统】传统——三个方向

- **向上(渊源)**:什么传统滋养了这位诗人?(前人、流派、继承的形式)
- **横向(同时代差异)**:这首诗与同时代处理同类题材者有何不同?——这是给诗定位**辨识度**的方式(让它成为*它自己*,而不只是"一首好诗")
- **向下(影响)**:这首诗让后来什么成为可能?

横向比较价值最高。向上向下定位诗在历史中;横向定位诗*作为它自己*。

### 【受】接受史——包含当下的阅读

不同时代如何从同一文本读出不同意义。一首经典诗是开放的容器,每个时代往里倾注自己的焦虑。

每一条必须有**具体出处**支撑(指名诗话、指名批评家、有据的文化挪用)。某个时代找不到出处,**就把那个时代拿掉**——一张诚实的三行表胜过一张虚构的六行表。

**小说家言不可作史实,但可作文化证据**:出自小说笔记(如薛用弱《集异记》"旗亭画壁"、冯梦龙《警世通言》等)的轶事,**不是信史**,不能当历史事实引证。但这类材料**可以作为"当时传播盛况"的接受史旁证**——它证明某诗在某时代已被推崇、已进入大众文化。处理时必须标注性质:"出自《集异记》小说家言,非信史,但反映唐代已被推为压卷"。史实与接受史旁证的界限,在这一维尤其要守清楚。

这个维度是整套方法里最容易产生幻觉的一维。具体的失败模式(模板移植、自我伪装、把接受史当历史而非当下)见文末"常见错误"统一表。

接受史的戏剧性各有不同。杜牧《过华清宫》起伏剧烈(红颜祸水 / 阶级压迫 / 资源劫持);苏轼《饮湖上初晴后雨》异常稳定(近千年一贯的"咏物名篇"共识)。**平淡的接受史是一个发现,不是需要粉饰的失败。** 照实平淡地报。

### 【文】作品本体(枢纽)——技艺分析

**至少覆盖以下四项**,按此顺序:

1. **炼字**——对每个承重字,论证为什么是*它*而不是近义词。不要罗列每个字;挑真正起作用的。一条好的炼字注记应能说明:所选的字承载了近义词无法承载的意义——一个制度术语而非通用词、一种更平滑的字会失去的重量或质感。

2. **结构**——诗的结构逻辑。描述这台机器:各句如何建立期待、转折、收束?常见模式包括起承转合、"三铺一转"的落差结构(三句铺陈、第四句反转)、嵌套框架。说出结构的名字;别再把内容复述一遍。

3. **声音**——平仄、节奏、听觉轨迹。按平水韵核查(核查铁律见 SKILL.md 第三阶段)。仔细处理入声字(如 一、骑作名词读 jì)。描绘听觉弧线——诗是加速、减速、末字叹息收束?声音从不偶然。无法核查时,按铁律诚实省略。

4. **意象序列**——视觉/语义序列及其逻辑。追踪诗依次把什么推到心灵之眼前,并追问为什么是*这个*序列而非别的。改变尺度(大→小)、改变模态(视→听→思)、改变语域(宏→密)的序列,通常通过排序本身在做论证。

## 六合收敛(第一阶段的收尾)

走完六维后,写一段**六合收敛**:一段话,呈现六维在原点(创作那一刻)的重叠。这是回报——整套方法就是为了让这一段成为可能而存在的。

模板:
> [若系年允许具体] 在[某时],作为[身份复合体]的[作者],立于[某地],带着[传统与生平包袱],目击了[某种世态]。六条支流在此点燃。它们产出的不是[某个简化标签],而是[诗所证明的结构性真理]。

若系年有争议,收敛仍成立——无论精确点火点在哪一年,支流都在汇聚。说明这一点。

**六合收敛的纪律**:它只能重述各维已在证据上确立的内容,不能引入新主张,更不能把推断(尤其是从【世】或【人】推出的解读)在这里"重述成真理"——假装汇聚本身就是证据。这是循环论证风险最高的环节,详见文末"常见错误"表的"六合收敛当证据"与"情感色温渗透"两行。

**写六合收敛前的强制动作**:按 SKILL.md 第三阶段的硬条件核查学界主流情绪定性——**必须列出至少 2 个权威源的具体色温措辞**,列不出 = 色温未核查,不得在六合收敛使用未经校准的色温。这是"情感色温渗透"失败模式的强制核查项——色温是 LLM 最容易自欺的环节,尤其对"以乐景写哀"的复调色温,LLM 系统性偏向表层的"乐"。

## 第四阶段——最终解读(核查后)

第三阶段返回修正。第四阶段 = 重新输出**两份产出**(解读与时间线),整合所有修正,并附:

1. **修正表**——每一处改动:原主张 → 修正 → *它如何改变了解读*。修正往往*深化*而不只是*纠正*——一个错的事实一旦改正,常常重新框定整个解读,让一切豁然开朗。把这些增益呈现出来,而不只是错误。

2. **诚实的系年注**——若系年有争议,收敛点是范围或明确标注的"最可能+存疑",绝不伪造精确度。

3. **收尾收敛陈述**——一段话:六条支流在原点重叠,证明了这首诗什么。

**两份产出都必须重新输出,不只是解读。** 收敛时间线(第二阶段)是同等 deliverable——核查修正也常常改变它(更精确的系年、新挖出的创作情境细节、被改正的事件)。很容易忘记时间线、只重新输出解读,因为解读感觉像"主"产出。别这样。两份产出回答不同的问题("它是什么" vs "它怎么来的"),两者都必须反映核查后的真相。

## 常见错误

| 错误 | 为何发生 | 修正 |
|---|---|---|
| **跳过【文】技艺分析** | 语境研究感觉像"正经活",技艺像可选 | 【文】是枢纽。没有它,你写的是历史,不是文学批评。 |
| **单一时代框架** | 假定"时代"是一回事 | 先辨认这首诗是单层还是多层语境;该多层就分层(咏史),该单层就单层(多数山水咏物) |
| **地理当背景** | "何处"感觉像琐碎 | 把空间当主动的构成(诗内)和隐去的代价(诗后) |
| **有生平无身份复合体** | 罗列事实感觉够了 | 把每个切面对应到它在诗里*启用*了什么 |
| **伪造平仄/韵部** | 技术性强,易含糊 | 按平水韵逐字核查。否则诚实省略。 |
| **从【受】里漏掉当下阅读** | 把接受史当成纯历史 | 当下阅读是最新的入口。指名它。 |
| **没有六合收敛** | 六个分节感觉够了 | 六合收敛是回报。方法就是为它存在的。 |
| **把事实核查当成润色** | "我最后再修事实" | 一个错事实能反转论点。事实核查是结构性的,第三阶段不可省。 |
| **【受】模板移植** | 复制上一首诗的接受表(唐宋/明清/...),用合理猜测重填空 | 每一行都要有找到的出处。诚实而短的表胜过编造而满的表。接受史的戏剧性各不同——照实报。 |
| **自我伪装成时代共识** | 把自己的【世】/【人】推断塞进【受】的"当下读法"行 | 这是循环式自我背书。要么引有据的主流读法,要么标注"本解读提出的视角,非共识"。 |
| **六合收敛当证据** | 让六合收敛用宏大散文把推断抬成已证真理 | 六合收敛只能重述各维在证据上确立的内容。它不引入新主张,自己不证明任何东西。 |
| **过拟合上一首诗** | 上一首读过的诗,塑造了新诗的预期形状(同样的维度角度、同样的表格结构、同"类型"的论点) | 每首诗都要从头过一遍。把此前的运行当成方法参考,绝不当成模板。 |
| **情感色温渗透** | 借上一首诗的情绪基调(冷峻愤慨、沉郁流放),染到新诗上——把学者读惬意的诗读成苦涩;或反过来,**把"以乐景写哀"的复调色温压成纯明亮**(LLM 对田园/旷达类表层"乐"有系统性偏好) | 写六合收敛前,按 SKILL.md 第三阶段的硬条件核查学界主流情绪定性:**必须列出至少 2 个权威源的具体色温措辞**,列不出 = 未核查;若权威源显示复调(表层明亮+深层苦闷),必须并列报两极,不得压平。 |

## 范例

**完整范例见独立的 `examples.md`**——里面有两个镜像对照的范例(杜牧政治讽刺诗 + 苏轼山水咏物诗),覆盖古典诗歌最常见的两种类型。

**何时读范例**:第一次执行本方法时读一遍;遇到新诗,先扫一眼范例判断它更靠近哪一极(政治讽刺 / 山水咏物 / 其他),但**不要套用范例的具体框架**——范例是"长什么样"的示范,不是模板。方法本体就在本文件里,不要被范例带偏。
