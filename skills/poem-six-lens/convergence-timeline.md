# 收敛时间线法

poem-six-lens 工作流 **第二阶段**的参考文件。主 SKILL.md 说明"要做";本文件说明"怎么做"。

## 核心思想

伟大的诗是一个**原点**:多条因果支流在此汇聚。收敛时间线**只追溯创作前半段**——所有流向诗的支流,止于创作那一刻。

创作前半段是**收敛性因果**:一切都流向诗的诞生,可追溯、有限。创作后半段是**发散性意义生成**:诗的接受史向外辐射,无边界,每个时代都在重读。这两者是不同范畴,属于不同呈现方式。时间线只取收敛的那半段;接受史属于六合解读的【受】维度,在那里按时代逐一呈现。

诗本身是**原点**——支流汇聚的终点,不是时间线上的一行。

## 五条支流(不是六条)

| 支流 | 是否上时间线 | 说明 |
|---|---|---|
| 【世】时代 | ✅ 行 | 时代事件,有日期 |
| 【人】生平 | ✅ 行(主干) | 生命事件,有日期——这是时间线的脊柱 |
| 【地】地理 | ✅ 但**附属于【人】** | 地理是生命事件的属性("某人、某地、某时"),不独立 |
| 【统】传统 | ✅ 行 | 诗人继承了什么——读过的书、吸收的传统。常是长跨度,需标明 |
| 【文】作品本体 | ❌ **不上线** | 这就是原点本身 |
| 【受】接受史 | ❌ **完全排除** | 创作后的发散,与时间线范畴不符 |

## 规定格式——两列表格

左列:时间。右列:该时间的所有事件,**每行一条,合并进一个单元格**(用 `<br>` 换行分隔)。

**为何用这种格式**:宽的多列表格(每条支流一列)可读性差——视线难以横跨六列追踪一行,且大多数单元格会是空的(很少有某个时刻在每条支流都有事件)。把支流竖向堆叠在一个单元格里,每个时间点自成一体、一目了然。

模板:

```markdown
| 时间 | 事件 (每行一个维度) |
|---|---|
| year | 【世】...<br>【人】...<br>【地】... |
| year | 【统】...<br>【人】... |
| **★ 原点** | **《诗名》诞生**<br>← 所有线索向此处收敛 → |
```

每行用【方括号】标注所属维度,让读者看清每个事件属于哪一面。

## 交汇反应

事件平铺罗列不够。时间线必须展示 **2-3 个交汇反应**——支流交叉、诗的必然性收紧的时刻。这些才是*因果*内容;没有它们,时间线只是一份加注的年表。

每个交汇应说明这次交叉*产生了什么新质*——不只是"这两件事同时发生了"。形式:

> **[支流 A] × [支流 B]**(日期范围):[A 带来的] 遇上 [B 带来的] → [由此产生的、向前流入诗的新质或压力]。

通常两到三个这样的交汇,就足以呈现支流如何编向原点。

## 诚实的系年

古典诗歌的系年经常有争议。**不要为了时间线有个干净的终点而伪造精确度。**

选项:
- 给出范围(如"大和至会昌, 约835–846")
- 选一个"最可能"并明确标注存疑(如"学界无定论,但大和九年说与杜牧分司洛阳后的行迹最吻合,故此处采此说")
- 说明**无论范围内取哪一年,收敛逻辑都成立**——支流仍在汇聚,只是精确的点火时刻不同

标注出的存疑是诚实的;未标注的猜测就是谎言。

## 不该出现在这条时间线上的内容

- **创作后的接受史(【受】)。** 不同范畴——发散,非收敛。它属于六合解读的【受】维度。
- **向下的传统(统·向下——诗影响了什么)。** 同理——创作后,发散。
- **诗本身作为"一行"。** 它是原点,用 ★ 标注,不是表中的一行。

## 上交前的自检

时间线定稿前,核对:
- [ ] 是否只有创作前事件?(无接受史、无向下影响)
- [ ] 【地】是否附着在【人】的事件上,而非独立?
- [ ] 是否为两列格式、支流用 `<br>` 堆叠?
- [ ] 是否识别并解释了 2-3 个交汇反应?
- [ ] 系年是否诚实标注争议?
- [ ] 原点是否用 ★ 标为终点、而非一行?

## 重要:第四阶段必须重做时间线(不是复用第二阶段那张)

第二阶段产出的时间线是**草稿**——它建立在对诗的初步理解上。第三阶段的事实核查几乎总会改变它:一个被修正的事件、一个更精确的系年、一个新挖出的创作情境细节、一个因色温修正而需改写的交汇反应。

**第四阶段必须按核查后的事实重新输出时间线,而不是把第二阶段那张原样搬过来。**

最容易犯的错:在第四阶段只重输出解读(因为它感觉像"主"产出),把时间线当成已经做完的事。这是错的。解读和时间线是两份平等的交付物,都回答一个独立的问题("它是什么" vs "它怎么来的"),两者都必须反映核查后的真相。详见主 SKILL.md 的"第四阶段交付检查"。
