# 六合读诗(Poem Six-Lens)

## 目标定位(方法的服务对象与成功标准)

**服务对象**:有好奇心与钻研精神、但无专业文学素养的深度读者。他们读诗不是为了做研究,而是为了**在一首诗上建立立体的认知**——不是平面地"知道意思",而是从时代、作者、地理、文学性、传统、接受史多个角度同时看见一首诗,形成可旋转、可细看的多维画像。

**成功标准**:产出能让这样的读者读完之后,对这首诗的理解从"知道这首诗讲了什么"升级为"看见这首诗为什么是这样、它好在哪、它在历史中长成了什么"。深度优先于普及——宁可让没有文学背景的读者需要稍作攀爬,也不要为了"易懂"把六维削平。

**适用场景**:古典诗歌的历史名篇(作者、系年、接受史都有据可查的篇目)。不适用于:作者完全不可考的诗、信息极度稀薄的小众诗、需要学术级考据的疑难篇目。遇这些场景,本方法不是工具,换个方法。

## 概述

一套用于产出**出版级古典诗歌解读**的方法。核心洞察:伟大的诗是一个**原点**——多条因果支流在此汇聚。要读懂它,必须追溯*每一条*流入它的支流,而不只是显眼的那几条(作者+时代)。

**六维,一个枢纽:**

| 维度 | 回答 |
|---|---|
| 【世】时代 · 【人】生平 · 【地】地理 · 【统】传统 · 【受】接受史 | 流入诗的五条因果支流 |
| 【文】作品本体(枢纽) | 技艺——它为什么是*艺术*,而不只是陈述 |

五条支流汇聚到【文】。读一首诗 = 轮流站在每个维度上,然后退后,看它们如何汇聚。

## 何时用

**适用于** 用户想要一首古典诗的深度/完整/透彻解读,或想"从多个维度/角度"理解一首诗。

**不适用于:** 简单翻译、一行注释、现代自由诗(本方法假设诗人是传统束缚下的古典诗人)。

## 工作流(强制——按此顺序)


### 第三阶段——穷尽式事实核查(铁律)

**建立在未经核查事实之上的解读只是草稿,不是交付物。跳过核查 = 跳过工作本身。** 核查不是润色步骤,而是*承重*阶段。古典诗歌密集地承载着日期、官职、地理距离、平仄分类、系年争议——错误易犯难辨,而一个错事实可能反转整篇论点(作者被放错位置就成了另一种目击者;一个有争议的年份被当成定论,会塌掉整个收敛逻辑)。

**范围:** 核查第一、二阶段产出的*每一条*事实主张——不是抽样。做到 MECE 覆盖。

**常见的待核查主张类别:**
- 作者:生卒、籍贯、家世(核查"祖父著X"这类主张——书名、卷数)
- 官职与幕府关系(谁、何时、具体何职)
- 历史事件(日期、规模、**作者实际距离**——目击还是听闻?)
- 文学史主张(谁影响了谁、篇数、卷数、收入何集)
- **诗学技术细节——平仄逐字、韵部、体裁、起式——按平水韵核查,绝不靠猜**(如 骑作名词 = 去声 jì;一 = 入声)
- 地理主张(距离、道路名、可行性——如易腐水果的保鲜极限 vs 实际路程)
- 系年——共识还是争议?若有争议,报范围,不挑一个
- **组诗全组**——若诗是组诗(二首/三首/...)的一部分,核查**全组每一首**,不只核查主角那一首。组诗其他篇常含决定性的内部证据(如苏轼《饮湖上初晴后雨·其一》"此意自佳君不会"揭示此诗作于游宴待客场合、宾客不懂欣赏——只核查其二会看不见这个事实)。**但注意:组诗内部证据支持某说 ≠ 排他性证明**——尤其在悼亡/赠妓、政治讽刺/私人酬赠这类"语境二可"的争议上,组诗内部证据只能**增强倾向**,不能构成定论。例如元稹《离思五首》其一"晓镜残妆"、其二"梳头"等闺阁细节兼容悼亡语境,但同样兼容赠妓语境——内部证据让悼亡说更可信,但不能据此排除陈寅恪赠莺莺异说。**组诗某首在主集未收、仅见于别本的处理**:若组诗中某首在诗人主集(如《瓯北集》)未收,仅见于别本(如《瓯北诗钞》)或他书辑录,**必须显式标注版本差异**(如"组诗其四《少时学语苦难圆》未见《瓯北集》,仅《瓯北诗钞》收录"),不得混入"《xx集》收入组诗 N 首"的说法——这既是校勘问题,也影响组诗完整性的判断。
- **学界对诗的主导情绪定性**——在写六合收敛之前,必须核查学界主流读法对诗的情绪基调(惬意 / 苦涩 / 愤慨 / 沉郁)是什么。如果你的解读色温与有据主流相矛盾(如学者读惬意、你读苦涩),你的框架错了,该改的是各维,不是六合收敛。这一项是防止"情感色温渗透"失败模式的强制核查。**这是 LLM 最容易自欺的环节**——色温藏在文本深层,LLM 的统计直觉经常抓错(尤其对"以乐景写哀""表面闲适实为孤愤"这类反统计的色温结构,LLM 系统性偏向表层的"乐")。因此色温校准**不得凭印象下判断**——必须满足以下硬条件:

  - **必须显式列出至少 2 个独立权威源**(鉴赏辞典条目、学者专著、有据诗话)对该诗情绪基调的具体措辞——不是笼统说"学界读为愉悦",而是列出"XX辞典:'此词表现人情之美与生活之趣';XX学者:'醉里二字暗含借酒浇愁'"这种**可核查的具体释义**。
  - **列不出具体来源措辞 = 未核查**。标为"色温未核查",不得在六合收敛使用未经校准的色温。
  - **警惕只采单一色温**:许多诗的真实色温是**复调**——表层明亮+深层苦闷并存(典型:辛弃疾闲居期田园词、苏轼贬谪期旷达词)。若权威源显示了这种复调,只采其中一极就是色温错误。**复调色温必须并列报两极**,不得压成单一情绪。

  **争议系年的双色温处理**:若该诗系年存在 2+ 候选且不同候选会导致色温冲突(如某诗悼亡读沉痛、赠妓读轻佻),**必须并列报两色温,不得只采一色温**;若两候选色温兼容(如元稹《离思》悼亡/赠莺莺两说都是庄重至情),可统一报,但注明兼容性。

**方法:** 按类别派出**并行后台子代理**(如:一个查生平、一个查历史/地理、一个查诗学技术)。每个返回:主张 → 裁决(✅/❌/⚠️) → 准确表述 → 来源 URL。

**资料源:** 中文诗歌优先用**中文资料**(维基中文、ctext.org、中华书局校注本、缪钺/钱锺书等专著)。

**不可妥协:** 若一条主张无法核查,**在最终产出里标注为"未核查"**。标出来的缺口是诚实的;未标的猜测就是谎言。

### 引用分级——L1/L2/L3(铁律)

第三阶段核查的事实主张,按"该主张错了/被删了,会不会让某个论点垮?"分三级:

| 级别 | 定义 | URL 要求 | 错了后果 |
|---|---|---|---|
| **L1 支撑性** | 支撑核心论点、进入修正表、作为色温校准依据 | **必须附 URL 到精确位置**(篇名/卷次/页码);无法精确化的,降级为 L2 并标注 | 论点垮 |
| **L2 语境性** | 提供背景,但不承重 | 鼓励附 URL;未附的标"(未核查)" | 解读细节受影响,主论点不垮 |
| **L3 常识性** | 一望而知的大众常识(李白是唐诗人、《长恨歌》白居易作) | 不要求 | 几乎无 |

**L1 的判定——客观触发为主,主观测试兜底**:

*硬触发(任一命中即自动 L1,无主观空间):*
- 进入**修正表**的主张
- 进入**六合收敛**的主张
- 作为**色温校准依据**的主张(学界情绪定性)
- **系年主张**(无论是否进修正表)

*软触发(主观兜底)*:不在以上四类、但删掉会让某个维度的论点垮的,也算 L1。判断测试——把这条主张删掉,某个维度或修正表的论点会塌吗?会塌 → L1。

**L1 引用 URL 的精确度要求**:不是"指向 ctext.org 首页"就叫精确。必须能从 URL 直接定位到具体记载位置(篇名/卷次/章节/页码)。若一条 L1 主张找不到精确 URL,**降级为 L2 并标"未核查",或直接从产出删除**——不要保留无 URL 的 L1。

**色温校准项的 URL 放宽(有条件)**:色温校准(学界对诗的主导情绪定性)是 L1 硬触发项,但色温本身是**解读的产出**而非单一外部事实——它综合自历代主流鉴赏。因此色温校准的 L1 URL 标准**有条件放宽**:若无可定位的单一 URL,**可以"(综合历代主流鉴赏)"留在 L1**——但条件是**必须明确列出综合了哪些来源(辞典名/诗话家)以及它们各自给出的色温措辞**。笼统标"综合历代主流鉴赏"但列不出具体来源和措辞 = 未核查,必须降级。这个条件是硬的——色温是 LLM 最容易自欺的环节,"综合"二字是最常用的溜出去的后门。

**【文】体裁判定进 L1 核查清单**:诗的体裁判定(古绝 vs 律绝、律诗 vs 排律、古体 vs 近体等)看似技术细节,实际影响【文】技艺分析的整个框架——把律绝当古绝分析,会推出错误的"破律"论证。因此**体裁判定属于 L1 主张**,必须核查(查主流工具书/学术共识),不得靠直觉。若学界对某诗体裁存在分歧(如苏轼《饮湖上》有古绝/律绝两说),按"系年 2+候选无共识"规则处理——列全候选,标主流倾向,不硬选一种。

**"后人归纳的通行评价"如何分级**:有些评价(如王之涣《凉州词》"古今七绝第一"、王之涣"旗亭画壁"轶事)在现代网页源里广泛传播,但**查不到单一精确出处**——它们是后人归纳或小说家言,不是古典诗话的原始论断。这类评价按以下规则处理:
- **不得当成学界定论**——禁用"学界公认为""已成为定论"等措辞
- **可标"(后人归纳,精确出处未锁定)"或"(综合现代选本/学人归纳)"**留在 L1,类似色温校准 URL 放宽
- **必须明确标注其归纳性质**——如"章太炎推许为古今七绝第一(具体篇名未锁定)""薛用弱《集异记》小说家言,非信史"
- **降级使用**——可作接受史维度的文化证据(证明某诗在后世被推崇),不可作史实或定论引证

### L1 引用的精确归属要求(针对错配失败)

URL 指向真素材,**不证明该素材属于该上下文**。这是最难抓的失败模式——核查子代理若不熟该领域,可能也认不出错配。L1 引用除 URL 外,还必须:

- **引文归属到精确篇名/章节**——不只说"出自《xx书》"。如"出自《新唐书·卷xx·xxx传》"而非"出自《新唐书》"
- **事件绑定到精确记载来源**——同一个事件在不同史料里记载可能冲突,必须明确采哪一处。如"采《旧唐书》说,《新唐书》作不同记载"
- **原文 vs 后人校勘显式区分**——"原文作X,杨慎/中华书局点校本校为Y"是两种不同的东西。把校勘混入原文当引文,等于伪造证据

**触发警惕的措辞**(写出来就停下来重新核查归属):
- "据《xx书》记载"(没有卷次/篇名)→ 不够精确
- "古人云"/"学者认为"(没有具体人)→ 不够精确
- "出自《xx集》"(没有具体篇名)→ 不够精确

**自检**:这条 L1 引用如果被一个对这一领域熟的人看到,他能立刻定位到具体段落吗?不能 → 归属不够精确,降级 L2 或删。

**两个二手源矛盾时的裁决**:当两个主流二手源(如维基中文 vs 百度百科)对同一事实给出不同记载(年份、姓名、官职等),**不得采多数说或随手表态"通行"**——必须上溯到一手史料(《新/旧唐书》原文、墓志铭、《全唐诗》卷次等)裁决。若一手史料也存分歧,按"系年 2+候选无共识"规则列全候选。例:王勃《檄英王鸡》系年——维基中文作 669,百度百科作 668;上溯《旧唐书》原文确认为乾封三年(668)。

**模式 C(错配)的核查路径——存在性核查,非正向搜索**:对"某学者在某书中讨论过某主题"这类主张,**不能靠正向搜索证伪**(搜"某学者是否讨论过"通常搜不到反证,因为"没讨论过"本身不构成搜索结果)。正确的核查路径是:**打开该书/该词条的目录、索引或相关页面,确认该主题是否实际出现**。若目标页面全文无该主题,识别为"真学者+真书+假主题"的错配,直接删除。例:核查"闻一多在《唐诗大系》中讨论过王勃《送杜少府》"——WebFetch 王勃该诗的百度百科词条全文,确认无"闻一多"字样,即证伪。

#### L1 数字主张——查无一手史料对应原文的标注(针对"推算值混入引文")

URL 指向真书,不等于该数字出自该书。L1 数字主张(生卒、年龄、系年、成书年,**以及人物姓名、字号、官职归属**等)除 URL 外,还必须能定位到**该事实实际出现的段落**。若一手史料中**查无对应文字**,必须:

- 标注"**通行说法,未见一手史料对应原文**"
- 并列陈述一手史料的实际措辞(如"通行作'年四十六',《xx墓志铭》原文作'年几五十'")
- 不得把后世推算值直接当引文传播

**触发警惕**:"通行说法""学者一般认为"+精确数字,但定位不到原始出处段落 → 这往往是后世推算值混入引文的信号(详见 examples.md 模式 A 亚型)。

#### 校勘异文的操作级指引

"原文 vs 后人校勘显式区分"的具体操作——当遇到异文时:

- **两版本都列出**,不要悄悄选一版(如"原文作'听唱',异文作'新唱'")
- **校勘归属**——若某版本是某校勘家的成果,显式标注(如"杨慎校为'万里津'",非《华阳国志》原文)
- **主流版本优先**——若存在主流通行本,以主流本为引文,异文作注;不要反过来
- **影响产出时显式说明**——若某异文选择会影响解读论点(如组诗其一"一杯当属水仙王" vs "半船旗鼓半红妆"会改变六合收敛写法),必须说明采哪一版、为什么
- **异文触发 L1 的硬条件**:异文选择若会改变【文】技艺分析(如"辅"=护卫 vs "俯"=俯瞰,推出完全不同的空间逻辑)或六合收敛写法,该异文主张**自动升 L1**,必须核查两版本的依据并显式说明取舍
- **用户/任务给定的异文也必须独立核查**——即使是用户输入或任务提示里提供的异文,也不能默认为真,必须和其他异文一样走版本核查。**查无版本依据的,显式标注"此异文查无依据,疑为记忆偏差或二次传播错误"**。核查的铁律是:不盲信任何来源,包括用户给定。

### 主题稀缺度自评(针对伪造定论失败)

LLM 在资料稀缺场景下,默认倾向是**装作有定论**而不是承认稀缺。第三阶段对每条 L1 引用,显式自评该主题的资料稀缺度。

**稀缺度由三个存在性信号判定(不用字数硬指标,只看有/无)**:

| 信号 | 丰富 | 中等 | 稀少 |
|---|---|---|---|
| 该诗人在主流鉴赏辞典(唐诗/宋诗鉴赏辞典等)有专条? | ✓ | — | ✗ |
| 该诗有独立的中文维基词条(非挂在作者词条下的子条目)? | ✓ | ✓/✗ | ✗ |
| 该诗的系年是学界主流定论(能查到共识源)? | ✓ | ✗(有争议) | ✗(无据可考) |

三个 ✓ = 丰富;两个 = 中等;零到一个 = 稀少。

**各密度的措辞要求**:

| 密度 | 措辞要求 |
|---|---|
| **丰富** | 正常陈述,附主流共识 URL |
| **中等** | 标注"学界存在不同说法",报范围不挑一个 |
| **稀少** | **降级为"假说"措辞**——禁用"学界定论""已成为共识""确证"等词;改为"一种说法""推测""尚无定论" |

**两类常见稀缺场域的具体操作**:

**A. 古籍成书年/版本年多源不同**——若多个权威源给出不同年份(如《琴学入门》有 1864/1867/1876 三说),**一律报范围(最小–最大),不挑一个**。在 L1 清单里显式列出所有查到的候选年,采主流说时标注"主流采 X 说,存在 Y、Z 异说"。不要硬选一个数字——这恰恰是模式 A 数字偏移的高发场域。

**B. 系年有 2 个以上学术候选但无共识**——必须**列全候选**,可标注倾向但**不得采为定论**。形式:

> 系年:学界存在不同说法。候选一:X 年(依据:...);候选二:Y 年(依据:...)。本解读倾向 Y 说(结构性证据更强:...),但非定论。无论取哪一年,收敛逻辑都成立。

即使倾向某一候选,也要明确说"非定论"——"倾向 + 非定论"是中等稀缺度系年的标准措辞,不是软弱,是诚实。

**警惕信号——出现以下措辞时强制触发稀缺度核查**:
- "学界普遍认为" / "已成为定论" / "确证" → 这是 LLM 在稀缺场景最爱用的伪装词
- 精确到某一年的系年(若无足够支撑) → 伪造精确度
- 引用某现代学者的"权威论断",但查不到该学者写过这一主题 → 伪造权威

**红线**:宁可在稀缺主题上说"资料不足以支持强论断,此处仅提假说",也不要伪造一个看似扎实的定论。前者是诚实的局限,后者是幻觉。

**补充——稀缺度的两层粒度**:上述判定按"该诗整体"给出基调。但同一首诗的不同主张,稀缺度可能不同——例如孟郊《登科后》整体资料丰富,但"及第年龄"这一具体细节(墓志铭"年几五十" vs 通行"四十六")却是中等偏稀缺。因此**整体稀缺度用于措辞基调;关键 L1 主张(尤其是数字、系年、归属类)需逐条自评稀缺度**——若某条 L1 在整体丰富的诗里却是稀缺点,该条单独降级为假说措辞,不拖累整体基调。

**稀缺度与 L1 的联动(强化)**:整体判为"稀少"的主题,其**所有数字/系年/归属类 L1 主张默认降级为 L2**,除非能定位到一手史料对应原文。理由:稀缺场域正是模式 B 高发场域,二手源的 unanimity 不构成可信依据(赵翼《论诗》系年"1784"就是二手 unanimity 但一手缺位的典型)。**只有定位到一手史料,才能升回 L1**——这是"装扎实"本能的硬性刹车。

### 第三阶段的已知局限(诚实声明)

第三阶段穷尽式核查能抓住**大多数**错误,但不保证 100% 可靠。已知三种失败模式(详见 `examples.md` "核查实证"节):

| 模式 | 表现 | 缓解 |
|---|---|---|
| **A. 数字偏移** | 真实素材里的年份/页码小幅偏移(如 1876 → 1864) | L1 引用的数字主张优先用可稳定核查的源(中华书局点校本、ctext.org),避开转述多次的二手网页 |
| **B. 资料稀缺场域的共谋幻觉** | 主代理和核查子代理是同一 LLM,在稀缺主题上可能同样编造,核查"通过"但实际错误 | 资料稀少的 L1 主张,**降级为假说措辞**(见上节),不要因为"核查通过"就升格为定论 |
| **C. 错配** | URL 指向真素材,但该素材不属于该上下文;核查子代理若不熟该领域,可能也认不出 | L1 引用必须满足精确归属要求(见上节);若主代理对领域不熟,**降级为 L2 而非强行升 L1** |

**用户建议**:对 L1 支撑性主张,尤其是涉及系年、作者归属、学界共识类,**做一次元核查**(在产出外部用独立工具/独立资料验证)。第三阶段的核查是必要不充分条件——它把幻觉概率降到很低,但不是零。

## 两份产出

完整运行产出**两份互补的交付物**:

## 产出契约(强制——final message 的格式与内容)

最终输出是**一份完整文档**,格式如下:

```
# 六合读诗:《{诗歌全名}》

> {诗词原文,每句一行——律绝每句一行,词每句一行、上下阕之间空一行 >}

## 六合解读

### 【世】{副标题}
{内容}

### 【人】{副标题}
{内容}

### 【地】{副标题}
{内容}

### 【统】{副标题}
{内容}

### 【受】{副标题}
{内容}

### 【文】{副标题}
{内容}

### 六合收敛
{收敛内容}

## 收敛时间线
{表格}
{交汇反应——粗体引导,不用标题}
{系年注——粗体引导,不用标题}
```

**格式约束(硬性)**:
1. 一级标题统一为 `# 六合读诗:《{诗歌全名}》`
2. 一级标题下用 blockquote(`>`)引用诗词原文,**每句一行**(律绝每句一行,词每句一行、上下阕之间空一行 `>`),不堆在一行
3. 只有 2 个二级标题:`## 六合解读` 和 `## 收敛时间线`
4. 六合解读下只有 7 个三级标题:6 个维度(`### 【世】...` 等)+ `### 六合收敛`。**除此之外不得有任何其他三级及以下标题**
5. 收敛时间线不使用三级标题——表格、交汇反应、系年注直接作为内容(粗体引导)

**内容约束**:
- 两份交付物都必须完整,禁止只返回摘要
- 第三阶段的**一切工作记录**(核查表、修正表、稀缺度自评、失败模式自检、色温校准注、运行总结等)都是内部记录,必须执行但**不输出给用户**。不要在最终产物末尾附加"关于本次运行""核查说明"之类的元信息——那属于工作日志,不是交付物
- 用户要的是解读和时间线这两份成品,不是你的工作日志

## 第四阶段交付检查(完成前逐项核对)

定稿时容易只重输出解读、漏掉时间线。这个检查清单是强制的——**没有全部勾完,第四阶段不算完成**:

**内部检查(不输出给用户,用于自查第三阶段是否真正走完)**:
- [ ] 核查表已穷尽第一、二阶段每一条事实主张(裁决 ✅/❌/⚠️/未核查)
- [ ] 修正表已附(原主张 → 修正 → 它如何改变了解读)
- [ ] 稀缺度自评已逐条判定(L1 逐条稀缺度)
- [ ] 色温校准已做(对照学界主流核查情绪基调)

**交付检查(这两份必须完整输出给用户)**:
- [ ] 六合解读已重新输出(六段散文 + 六合收敛,整合所有第三阶段修正与深化)
- [ ] **收敛时间线已重新输出**(不是用草稿阶段那张——必须反映核查修正:更精确的系年、新挖出的创作情境、被改正的事件、被改写的交汇反应)。若系年有争议,作为表格附注写明

**红旗——若发现自己在想这些话,停下来,时间线还没完成。每条后面跟着对应的正向操作:**

| 想法(危险信号) | 正向操作(改做这个) |
|---|---|
| "解读把意思说清楚了,时间线就是辅助" | 两份产出地位平等——解读答"是什么",时间线答"怎么来的"。先按交付清单把两份都做完再宣布结束。 |
| "时间线上一轮输出过了,不用再发" | 那是旧色温、旧框架的版本。按核查后的事实重做一张,对照修正表逐条改。 |
