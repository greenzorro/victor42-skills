# 完整范例

poem-six-lens 的范例库。**这些是"长什么样"的示范,不是"必须照搬"的模板**——读一眼就够,不需要每次执行都重读。方法本体见 `interpretation-method.md`。

## 当前范例

下面五首诗覆盖古典诗歌最常见的几种类型——**政治讽刺**、**山水咏物**、**送别**、**抒情**、**以诗论诗**。它们的时代跨唐、宋、清三代,体裁含律绝、古绝、折腰体,情感色温从冷峻到明亮到狂喜到锋利各有不同。**放在一起,是为了防止把任何一种诗型误读为"诗的标准长相"。** 读到一首新诗时,先问它更靠近哪一首的类型,而不是默认套用任一范例的框架——也包括不要默认"所有诗都该有双重时代""所有送别诗都该苦涩"。

| 范例 | 诗 | 类型 | 色温 | 结构引擎 |
|---|---|---|---|---|
| 一 | 杜牧《过华清宫绝句·其一》 | 政治讽刺(咏史) | 冷峻锋利 | 三铺一转·末句反转 |
| 二 | 苏轼《饮湖上初晴后雨·其二》 | 山水咏物 | 明亮惬意 | 二铺一转一合·升维 |
| 三 | 王维《送元二使安西》 | 送别 | 深情含蓄 | 两铺一转·末句拉开 |
| 四 | 孟郊《登科后》 | 抒情(登第) | 狂喜 | 二元对立·瞬间翻转 |
| 五 | 赵翼《论诗五首·其二》 | 以诗论诗(元诗) | 冷峻明亮 | 二铺一转一合·逻辑递进 |

### 范例一(政治讽刺诗)——杜牧《过华清宫绝句·其一》

> 长安回望绣成堆,
> 山顶千门次第开。
> 一骑红尘妃子笑,
> 无人知是荔枝来。

六维在这首诗上的完整运行。这是示例,不穷尽——它展示*方法如何落到具体文本上*。

### 【世】——双层语境(咏史诗的特征)
- **所咏之世**:盛唐天宝。华清宫是皇权的"度假版";"以天下奉一人"推到极致。
- **写作之世**:晚唐大和会昌。距安史之乱约七十余年。帝国正在重演玄宗晚期的病灶:宦官掌神策军并弑君(宪宗、敬宗),藩镇形同独立,牛李党争撕裂朝堂。
- **引擎**:杜牧写盛唐是为了诊断晚唐。诗的政治锋芒就在这古今同构里——每个晚唐读者都在历史表象下听见了对当下的警示。

### 【人】——身份复合体
杜牧不只是"一个晚唐诗人"。让他成为这种素材独特反应器的复合体:

- **京兆杜氏后裔**:祖父 杜佑 著《通典》(二百卷,制度史巨著)。他带着制度史家学——对国家*应该*如何运转的痛感,这把目睹它失序的疼痛磨得更利。
- **兵法注者**:著《杜牧注孙子》三卷(收入《十一家注孙子》)。他懂军政物流——所以"驿马运水果"刺痛*他*的程度,是刺不到李商隐的。
- **牛李党争夹缝人**:两不讨好,仕途坎坷。
- **甘露之变幸存者**(见下方【地】):这让他不是"目击者",而是嗅到血腥味、抽身而出的人。

每个切面在诗里都做具体工作——没有一个是闲笔生平。

### 【地】——空间作为主动的构成
**(a) 诗内——电影式推近:**
```
长安(回望·远景) → 绣成堆(全景) → 千门(中景·次第开)
   → 一骑红尘(近景·动) → 妃子笑(特写) → 荔枝(微距·真相)
```
每一句把镜头推近一格。意象在缩小,道德重量在加重。这是**反比例修辞**——结构本身即论证:对象越小,控诉越重。

**(b) 诗后——被压掉的路**:诗只展示了终点(宫门开、马蹄到、妃子笑)。它压掉了路——荔枝自涪州(今重庆涪陵)出发,经"荔枝道"(涪陵—达州—西乡—子午谷—长安),全程约2000里,三日昼夜兼程。子午谷本身是军事要道(三国魏延奇谋所指)。路被压掉,正是批判本身:诗信任读者去想象那条文本拒绝展示的血路。

### 【统】——横向定位
晚唐三家咏史大家,笔法各异:

| 诗人 | 笔法 | 读感 |
|---|---|---|
| **杜牧** | **明白如话,末句反转** | 像调查记者——锋利、清醒、一击致命 |
| 李商隐 | 朦胧含蓄,典故层叠 | 幽深、缠绵、意在言外 |
| 刘禹锡 | 苍凉雄浑,感慨深沉 | 沉郁、开阔、历史沧桑 |

这是杜牧的**辨识度**:三人中最"新闻性"的一位。他不让你跋涉典故——他让你*看见荒诞*。

### 【受】——包含当下
| 时代 | 读法 | 投射 |
|---|---|---|
| 唐宋 | 以史为鉴的政治寓言 | 对当朝的警示 |
| 明清 | "红颜祸水"框架 | 把亡国归罪于女性 |
| 20世纪阶级史观 | 阶级压迫 | 荔枝 = 民脂民膏 |
| 当代大众文化 | 浪漫化消费(奶茶/快递文案) | 掏空讽刺,只剩"妃子笑"的甜 |
| **当下这一读** | **权力对稀缺资源的私人劫持** | 一个跨时代的治理隐喻 |

### 【文】(枢纽)——技艺
- **炼字**: 一骑 (不是 一马——骑是驿传系统的建制单位,这个词本身就是控诉); 堆 (不是 聚——暗示沉重、不可持续); 红尘 (尘土 + 俗世虚妄,双关); 无人知 (不是"没人看见"而是"这种荒诞超出常人想象边界")。
- **结构**: 三铺一转的落差结构。前三句铺庄严期待(绣成堆 → 千门次第开 → 一骑红尘);第四句揭示一个微小的真相(荔枝)。读者一脚踏空。
- **声音**(按平水韵核查): 平起首句入韵, 押上平十灰。听觉弧线: 由远及近、由急转缓、末字"来"轻轻一收, 如叹息。"一骑" 入声短促, 拟马蹄。
- **意象序列**: 绣(华) → 门(开) → 尘(动) → 笑(情) → 荔枝(实)。从人工之华到自然之实;从宏大到微小;重量与体积成反比。

### 六合收敛
在原点——一个甘露之变的幸存者,立于华清宫废墟之上,带着制度史家王朝的家学和兵法注者的精密,目睹自己的帝国在重演他在历史里诊断的病灶。六条支流在此点燃。它们产出的不是"对玄宗的讽刺",而是一个结构性真理:**当一个系统最稀缺的资源可以被最高权力无约束地调用于私欲时,崩溃已写进逻辑里。** 杜牧没说这句话。他只让你看一颗荔枝。

**关于本例**
- 系年有争议(大和说 / 开成说 / 会昌说)。上方使用的"大和九年"框架是"最可能+存疑"——它和杜牧分司洛阳后的行迹、以及诗中"过"(路过)的逻辑相吻合。无论如何,收敛都成立。
- 本例为示例。真实运行会对每一维挖得更深,并在第四阶段定稿前走第三阶段事实核查。

### 范例二(山水咏物诗)——苏轼《饮湖上初晴后雨·其二》

> 水光潋滟晴方好,
> 山色空蒙雨亦奇。
> 欲把西湖比西子,
> 淡妆浓抹总相宜。

与杜牧那首镜像相对:明亮而非冷峻,升维而非反转,惬意而非失意。注意这首诗如何**用几乎相反的策略达到同样高的成就**——这说明六合方法是形态生成器,不是模板。

### 【世】——单层语境(山水咏物诗的常态)
- **所咏之世**:北宋熙宁年间的杭州,东南第一形胜,西湖经唐白居易疏浚、五代钱氏营建,至宋初已是士大夫游宴胜地。
- **写作之世**:熙宁二年(1069)起王安石变法,新旧党争撕裂朝堂。苏轼上书论新法之弊,**熙宁四年(1071)自请外放,十一月到任杭州通判**。
- **关键校准**:与杜牧那首的"古今同构"引擎不同,这首诗的"世"作用机制是**把政治挫折转化为审美对象**——但学界对此诗的情绪定性是"旷达豁达、对美的赞叹",**不是失意者的苦吟**。写这首诗前必须先校准色温:**苏轼通判杭州是他一生中最惬意幸福的时期之一**,他自况"中隐"。色温错了,整篇解读都会歪。

> **组诗其一**(作系年与内部证据用):朝曦迎客艳重冈,晚雨留人入醉乡。此意自佳君不会,一杯当属水仙王。
> (注:末句主流版本作"一杯当属水仙王"——诗人把客人错过的美敬给湖神;另有"半船旗鼓半红妆"等异文,非主流版本。)

### 【人】——身份复合体(每个切面在诗里做什么)
- **蜀学传人 + 全才型士大夫**:启用的是**抽象与概括能力**——把具体西湖晴雨,概括成近乎普遍的命题("总相宜")。
- **画家型士大夫**(诗、文、书、画皆精):启用的是对**视觉范畴**("晴/雨""浓/淡""光/色")的精密辨析——这是受过画学训练的眼睛才会做的区分。
- **被外放到杭州(而非更远)的通判**:启用的是**这次外放在生活感受上的可承受性**。若他被贬到黄州(1080 后)或儋州(1097 后),绝写不出这种色调。
- **以理趣入诗的革新者**:启用的是把"比"从修辞手段推成**近乎哲学命题**的能力。

### 【地】——空间作为抽象化
**(a) 诗内——气象学的全景**:全诗不写湖的某一角,而写湖的**两种气象状态**(晴、雨)的全貌。这不是地理描写,是地理的**抽象化**——把"一处具体的山水"提升为"一种能同时容纳对立面的本质"。

**(b) 诗后——杭州作为外放地**:苏轼被外放到北宋最明丽的都市之一,而非偏远贬所。这次"政治挫折"在生活感受上并不晦暗——**这是本诗明亮基调的现实条件**。对比后来的黄州《赤壁赋》、儋州《六月二十日夜渡海》——同一个人,地理不同,色温迥异。

### 【统】——核心创变:翻转"以神女写地"的方向
- **向上**:六朝至唐的山水诗传统(谢灵运→王孟);《诗经》以来的"比"的传统。但苏轼把"比"从修辞格升维成命题工具。
- **横向**(同时代辨识度):与同时代咏物写景者相比,苏轼的特点是**明白如话而理趣盎然**——不逞技法、不用僻典,却从日常抽出近乎普遍的命题。
- **核心创变**:苏轼是使**真实历史美人(西施)成为真实山水(西湖)的喻体**这一喻式深入人心的关键诗人——具体的、对等的、可互换的。此前是"以神女写地"(宋玉、曹植《洛神赋》),神女是虚指、是象征;苏轼翻转了方向。**是否为绝对首创,尚无文献定论**(中国作家网明确称"是不是首创,没有去考证过");但**苏轼是使此喻式确立并广为流传的关键人物**,这一点有据。他对此喻极为自许,在《次**前**韵答马忠玉》"只有西湖似西子"等多首诗中反复使用——《次前韵答马忠玉》作于元祐六年(1091)苏轼以龙图阁学士再知杭州时期,距通判杭州(1073)已约 18 年,说明这种偏爱是终身性的,而非一次即兴。
- **向下**:此诗使"西子湖"成为西湖的别名,沿用至今。

### 【受】——稳定而非戏剧化
| 时代 | 读法 | 出处 |
|---|---|---|
| 宋元以来 | 公认为咏赞西湖的咏物名篇 | 收入《东坡全集》;后世诗话一致推崇 |
| 清代 | 王文诰"前无古人,后无来者"的极评 | 王文诰《苏文忠公诗编注集成》 |
| 清末 | **"遂成为西湖定评"**——此喻成为西湖的别名 | 陈衍《宋诗精华录》(评"欲把"二句) |
| 当代 | 中小学语文教材长期收录;宋诗写景代表作;"极其准确而精到的艺术概括" | 陈邦炎《宋诗鉴赏辞典》(独立条目,与陈衍非同一人) |

**与杜牧那首的关键差异**:杜牧《过华清宫》的接受史起伏剧烈(红颜祸水 / 阶级压迫 / 资源劫持),每个时代投射不同焦虑;**这首诗的接受史异常稳定**——近千年一贯地被读为"咏赞西湖的名篇",没有剧烈读法变迁。**平淡的接受史是一个发现,不是需要粉饰的失败。** 这种稳定本身说明:这首诗没有为后世留出重新投射焦虑的缝隙,因为它本身就是一首开放的、明亮的诗。

### 【文】(枢纽)——升维结构(与杜牧"落差结构"镜像)
- **炼字**:潋滟(满溢跳动,两字皆去声,听觉短促拟光跳)/ 空蒙(湿润空灵,两字皆平声,拖长与潋滟形成听觉对比——字音模仿所写气象)/ 方(正当其好,时间的恰好性)/ 亦(并立不偏,全诗伦理姿态的核心)/ 总(全称概括)/ 宜(关系性判断而非属性——苏轼对"美是什么"的回答:美是相宜)。
- **结构**:**二铺一转一合**(与杜牧"三铺一转"镜像)。前两句对称铺陈(晴好/雨奇)→ 第三句转(用"比"嫁接历史美人)→ 第四句合(全称判断)。核心机制是**升维**:现象(晴/雨)→ 本质(西子)→ 命题(相宜)。每一步提升抽象层次,28 字完成三级跳。
- **声音**(按平水韵核查):**七言律绝,仄起不入韵**, 押上平四支。**四个入声字易错**(色、亦、欲、抹——现代普通话不像仄,但平水韵皆入声=仄)。听觉弧线:潋滟短促拟晴光,空蒙拖长拟雨意,字音与气象同构。
- **格律的让步**:第三句"欲把西湖比西子"第六字"西"是平声,与第四字"湖"未平仄交替,构成拗句——苏轼为"西湖—西子"两个"西"字的语义对仗,**主动牺牲了平仄交替**(在律绝允许的变格范围内)。规则为人服务。
- **意象序列**:水光(晴·动)→ 山色(雨·静)→ 西子(人·理想化)→ 淡妆浓抹(关系命题)。每步升维。

### 六合收敛(注意色温校准)
在原点——熙宁六年(1073)正、二月间,杭州通判任上的第三年。一个因政见不合而自请外放的士大夫,在西湖上设宴待客(见组诗其一:"朝曦迎客艳重冈,晚雨留人入醉乡")。客人醉倒了,错过了雨景(此意自佳君不会);诗人独醒,看见了客人看不见的东西:西湖在晴时也好、在雨时也奇。带着蜀学的通达、画家的眼睛、和对这次外放的可承受之感,他把这一刻写成了一首关于"美在不同状态下都成立"的诗。六条支流在此点燃——**它们产出的不是"失意者的自我安慰",而是一个结构性发现:真正的美,是能容纳对立面的那种东西**。

**关于本例**
- 系年为学界主流定论:**熙宁六年(1073)正、二月间**,无重大争议。
- **组诗其一是决定性内部证据**:"此意自佳君不会"揭示此诗作于游宴待客场合,客人醉倒错过雨景,诗人独赏。**只读其二看不见这个互文**——这是 skill 要求"组诗必须全组核查"的典型验证。
- 本例为示例。真实运行会对每一维挖得更深,并在第四阶段定稿前走第三阶段事实核查。

### 范例三(送别诗)——王维《送元二使安西》(渭城曲)

> 渭城朝雨浥轻尘,
> 客舍青青柳色新。
> 劝君更尽一杯酒,
> 西出阳关无故人。

与前两首不同:这首诗的引擎不在"讽刺"或"升维",而在**减法**——它把所有可能用的修辞都拿掉,只留下一个事实。而"事实本身就够了"这件事,本身就是最深的技艺。

### 【世】——单层语境(盛唐送别)

单层语境的诗,活在诗人当世。但"盛唐"在此承担三件具体的事:

第一,**国势与边塞的开放**——开元天宝年间,安西都护府统辖四镇,从敦煌西出阳关经塔里木盆地可达葱岭以西。元二要去的地方不是不可达的绝域,而是大唐帝国的西陲军政辖区。**这使得这首送别诗的底色不是绝望的"死别",而是绵长的"远别"——它有现实重量,但不至于悲怆**。

第二,**送别文化的成熟**——折柳、长亭、劝酒、阳关、灞桥,这些意象在盛唐百年内凝结为稳定的符号系统。王维用着它,也在超越它。

第三,**仕途与边塞的常态化勾连**——文人士子赴边入幕是常见出路,元二使安西在盛唐语境里是相对寻常的事。这让诗的悲伤不至于过分,却让"无故人"三个字的重量反而更实。

### 【人】——身份复合体:过来人 × 辋川主人

让王维成为这首诗独特反应器的复合体,有一个决定性切面:**他亲自走过那条路**。

开元二十五年(737),王维以监察御史身份奉使出塞,赴河西节度使崔希逸幕府任判官,亲历凉州(今武威),写过"大漠孤烟直,长河落日圆"(《使至塞上》)。**这意味着他对"西出阳关"四个字的理解,不是想象,是目击**。当他对元二说"西出阳关无故人"时,那是一个已经走过那段路的人,对一个即将走完全程的人说的话。这种"过来人"的语气,是李白、王昌龄写送别时未必有的(他们大多没去过那么远)。

第二个切面:**半官半隐的辋川主人**。约天宝三年(744),王维营蓝田辋川别业,"身在朝廷,心在山林"。他对"故人"二字的理解,不是寒暄用语,而是**一种生活方式的核心——人和人之间真正能共处的、不必解释的相知**。元二这一去,这种相知被地理切断。

第三个切面:**诗佛**。王维后世被称为"诗佛",他的山水诗常被读为空灵恬淡。但《送元二》的色温**不是空灵**,是温热的、不舍的。这说明王维不是一个色调的诗人——把这首诗读进他的整体,会看见一个被"诗佛"标签压平了的诗人,其实有非常饱满的人间温度。

### 【地】——空间作为主动的构成

**(a) 诗内的空间序列——由近及远、由柔及苍**:

```
渭城·客舍(近·柔) → 一杯酒(特写·温) → 阳关(远·苍) → "无故人"(更远·空)
```

全诗四句,空间三跳:前两句钉在渭城(长安西郊),湿润清丽;第三句特写收束到一只酒杯;第四句突然拉开——**阳关、无故人**——一句之内把视线从眼前一杯酒甩到千里之外的玉门关外。**末句空间骤然拉长**,是这首诗的引擎。

**(b) 诗后的地理——那条被压掉的路**:

诗只展示了渭城(起点)。它压掉的是**从渭城到安西的整条河西走廊**——陇右、河西、凉州、甘州、肃州、沙州、阳关,再西行入塔里木盆地,直至龟兹(安西都护府治所)。这条路,王维本人走过前半段(到凉州);元二要走完全程。**诗把数千里的苍茫折叠进一句"西出阳关",把现实里那条路的份量全都压在一只小小的酒杯上**。

### 【统】——横向定位:最克制的送别

盛唐送别诗,几座高峰各有时态:

| 诗人 | 送别名篇 | 笔法 |
|---|---|---|
| **王维** | 《送元二使安西》 | 清丽含蓄,末句突然拉开 |
| 王昌龄 | 《芙蓉楼送辛渐》 | 格调清刚,"一片冰心"自明 |
| 高适 | 《别董大》 | 豪迈悲壮,"莫愁前路无知己"反转 |
| 李白 | 《黄鹤楼送孟浩然之广陵》 | 意在言外,"唯见长江天际流" |

这是王维的辨识度:**最克制的送别**。高适用反话(莫愁)、李白用孤帆远影、王昌龄用冰心;**王维什么都没用——只用一句"无故人"的直陈**。辨识度就在这"不做"里:所有人都做了什么,王维什么都没做,反而最沉。

### 【受】——由送别小诗到文化母题

| 时代 | 读法 | 出处/载体 |
|---|---|---|
| **盛唐当世** | 即被谱曲入乐府,名《渭城曲》。唐人饯别宴席广为传唱。 | 白居易《晚春欲携酒寻韦庶》"相逢且莫推辞醉,听唱阳关第四声"已用此典 |
| **北宋** | 已不知确切唱法。苏轼得古本《阳关》,著《记阳关第四声》,辨析"三叠"本义:"得古本《阳关》,其声宛转凄断……每句皆再唱,而第一句不叠" | 《东坡志林·记阳关第四声》 |
| **明代** | 推为唐人七绝极致之一(李东阳《麓堂诗话》、胡应麟《诗薮》均有推崇,精确引文卷次网络源不一) | 综合明人诗话 |
| **清代** | 张鹤编《琴学入门》(同治三年/1864 成书),改编为此曲最通行的谱本,沿用至今 | 《琴学入门》 |
| **当下** | "阳关"已成为"离别"的同义词;"西出阳关无故人"被反复化用 | 综合观察 |

**接受史的戏剧性**:这首诗由一首送别小诗,演变为一种音乐曲体(《渭城曲》),再演变为一个文化符号("阳关"="离别")。这种三级跃迁,在整个古典诗歌里都是罕见的。

### 【文】(枢纽)——减法的胜利

- **炼字**:**浥**(轻轻沾湿,不是冲洗——一个字确立分寸:一场刚刚好的雨);**新**(刚发生的时间性,与"无故人"的恒久空旷形成反衬);**更**(明知不可留还要再留一刻的拖延);**尽**(喝完这杯就没了);**无故人**(三个字直陈,无修饰、无修辞、无夸张——全诗的命眼)。
- **结构**:**两铺一转的落差结构**。前两句铺景(朝雨·柳色),第三句转(劝酒·温),第四句反合(阳关·无故人·空)。前三句把读者温柔地按进一只酒杯,第四句突然把酒杯翻向千里之外。**温热与空旷的对比,就是这首诗的全部意思**。
- **声音**(按平水韵核查):七言绝句,**平起入韵**,押**上平十一真**(尘、新、人)。**关键格律事实——这是"折腰体"**:第二句与第三句之间应粘而失粘,前人因这首诗专称此式为**"阳关体"**。第三句末字"酒"(仄收)是全诗唯一的仄声落脚——**这是听觉上的"折腰",也是情绪上的"折腰"**:前三句的温润在此突然一断,第四句才以长平声"人"字收束,如一声长长的叹息。
- **意象序列**:朝雨(天·湿)→ 轻尘(地·微)→ 客舍(人·暂)→ 柳色(物·新)→ 酒(情·温)→ 阳关(地·远)→ 无故人(空·绝)。序列在缩小(从天到酒杯),又在末句突然拉到最远、最空。**收与放的对比,就是这首诗的空间论证**。

### 六合收敛

在原点——一个已经亲自走过那条路前半段的诗人,立于渭城客舍,带着对盛唐边塞真实距离的身体记忆、对辋川式相知生活的珍视、和对折柳送别千年习俗的清醒使用,送一位将走完全程的朋友。**春雨刚浥过轻尘,柳色清新得像第一次出现**。他什么都没说——没有叮咛、没有许诺、没有感叹,他只说:再喝一杯吧,出了阳关,就没有故人了。六条支流在此点燃。**它们产出的不是"深情的离别的描绘",而是一个结构性的发现:真正最重的不舍,是用最直白的陈述呈现的——"无故人"三个字不用任何文学手段,恰恰因为这件事的份量,任何手段都承载不了**。

**关于本例**
- **系年学界无定论**。主流仅笼统系"安史之乱前(755前)"。结合王维 737 年亲历河西的行迹,本解读倾向开元中后期至天宝年间(约 737–754),但非定论。无论取哪一年,收敛逻辑都成立。
- **"过来人"视角是本解读最关键的深化**:王维 737 年出塞亲历河西,使"西出阳关无故人"从想象变为目击者的陈词。
- 本例为示例。真实运行会对每一维挖得更深,并在第四阶段定稿前走第三阶段事实核查。

### 范例四(抒情诗·登第)——孟郊《登科后》

> 昔日龌龊不足夸,
> 今朝放荡思无涯。
> 春风得意马蹄疾,
> 一日看尽长安花。

与前几首不同:这首诗的引擎不在外部事件的讽刺或送别,而在**一种压抑了半生的情绪在某个瞬间的爆炸性释放**。它的色温是狂喜——但只有在核查了诗人的真实处境后,这种狂喜才显示其重量。

### 【世】——单层语境,但有制度性暗流

明面是中唐贞元年间(785-805)的长安,进士科难如登天——"三十老明经,五十少进士"(王定保《唐摭言》),五十岁中进士都算年轻。贞元十二年丙子科取进士三十人,状元李程,主考礼部侍郎吕渭。

暗流是这个时代提供的**制度性苦难的总量**:中唐进士科录取率极低(岁贡八九百人,录取二三十人)。这首诗的明亮,是建立在这个时代的制度性残酷之上的——没有"五十少进士"的时代底色,"一日看尽长安花"的狂喜就没有反衬的厚度。

### 【人】——为什么偏偏是孟郊?

- **寒素处士**:父孟庭玢仅任昆山尉,家清贫。《旧唐书》本传说他"少隐于嵩山,称处士"。这个身份启用的是**体制外者一朝被体制接纳时的剧烈反差感**。
- **年近五十方登第的迟到者**:韩愈《贞曜先生墓志铭》原文称"**年几五十**,始以尊夫人之命,来集京师"——"年几五十"(将近五十),**而非后世转述的精确"四十六"**。这个切面启用的是**时间焦虑**——"一日看尽"的"一日"之所以如此急切,正因为前面已耗去了近五十年。
- **苦吟诗人**:韩愈评其作诗"钩章棘句,掐擢胃肾"。这个切面启用的是**反差本身**——一个以"苦"为诗学底色的人,突然写出这样一首"快"诗。
- **奉母命应试的孝子**:墓志铭两次强调"始以尊夫人之命"——孟郊应试是奉母之命。这个切面启用的是**这首诗的情感合法性**——它的狂喜不是个人功名心的膨胀,而是半个世纪未能尽孝的寒素之子,终于在老母有生之年交出答卷的释然。

### 【地】——长安作为制度性终点

**(a) 诗内的空间——从内心到城池的扩张**:

```
昔日(内心·龌龊) → 今朝(内心·思无涯)
   → 春风(身体·马蹄疾) → 长安(城池·尽花)
```

前两句还在内心世界打转,后两句突然把镜头拉到身体和城池。**空间的爆炸性扩张,正是狂喜情绪的空间化**。

**(b) 诗后的地理——长安作为曾经拒绝他的地方**:

诗把长安写成一个可以被"一日看尽"的繁花都市,但它压掉了一个事实:**长安对寒素文人而言,首先是一个不断拒绝他的地方**。孟郊至少两次在这座城里落第——《再下第》"两度长安陌,**空将泪见花**"。同一座城,同一个春天,同一种花——三年前他用"泪"看,今日他用"得意"看。**地理未变,人变了**。

### 【统】——横向定位:以最少的技艺承载最大的情绪

与同时代韩愈的奇崛、李贺的诡丽、元白的通俗相比,孟郊这首诗的辨识度是**极度的直白与极度的反差**。它不靠典故、不靠奇字、不靠技法炫示——它靠的是**"昔日/今朝"的二元结构 + 一个夸张到不可能的动作("一日看尽")**。

**最深的一层**(核查中的关键发现):**《登科后》与孟郊自己的《落第》《再下第》押同一个下平六麻韵**。"空将泪见花"(落第)与"一日看尽长安花"(登第)——同一个韵部,同一座城,同一种花,只等情绪翻转。**这不是一首孤立的得意诗,而是孟郊个人诗史内部一次押韵的翻转**。

### 【受】——戏剧性的反转

| 时代 | 读法 | 投射 |
|---|---|---|
| 中唐当代 | 孟郊友人的真诚推崇 | 韩愈奉为"复兴古代诗歌精神的诗坛大师" |
| 宋代 | **色温反转的开端** | 苏轼《祭柳子玉文》"郊寒岛瘦"定型;宋人开始批评孟郊"胸怀不广":落第时心如刀刻,及第后得意猖狂,变化太快 |
| 元明清 | "金榜题名"的经典意象 | 两个成语("春风得意""走马观花")固化 |
| 现代学界 | 为孟郊"正名" | 苦了大半辈子终于得偿所愿,那一刻的欣喜若狂是最真实的人性;同时出现"以乐写悲"的深层解读 |
| **当下这一读** | **一组内部互文的枢纽** | 这首诗的真正力量,在和孟郊自己的落第诗押同一个麻韵——从"泪见花"到"看尽花",三年之间,同一韵部,情绪翻面 |

### 【文】(枢纽)——二元对立的瞬间翻转

- **炼字**:**龌龊**(处境的逼仄与心思的局促,带自我厌弃的锐度);**放荡**(古义的精神无拘无束,与"龌龊"精确对仗);**疾**(马蹄的"快"同时也是心的"急"——因为等得太久);**尽**(不可能的动作——"一日看尽长安花"暴露的不是视觉,是**对这座曾经拒绝他的城市的占有欲**)。
- **结构**:**二元对立的瞬间翻转**。前两句是静态对立(昔 vs 今),后两句是动态奔涌(得意→马蹄疾→一日→看尽)。**全诗的动能,来自一个压抑了半生的人,在某个瞬间彻底松开**。
- **声音**(按平水韵核查):**七言古绝**(非律绝)。押**下平六麻**(夸/涯/花)。首句"昔日龌龊不足夸"——**一连六个仄声字**(其中五个入声),末字才平。这种密集的入声堆叠,在听觉上产生**压抑、短促、憋闷**的效果——恰是"昔日龌龊"的情绪听觉化。第二句末三字"思无涯"成**三平调**,声音突然拖长、放开——恰是"思无涯"。**古绝的自由度,让孟郊能用平仄的"不协律"来做情绪的论证**。
- **意象序列**:龌龊(抽象·心理)→ 放荡(抽象·心理)→ 春风(自然·触觉)→ 马蹄(身体·听觉)→ 长安花(城池·视觉)。**从内心冲向世界的过程**。

### 六合收敛

在原点——贞元十二年(796)春,长安放榜之日。一个年近五十(墓志铭原文"年几五十",通行推算作四十六,**未见一手史料对应"四十六"原文**)的寒素处士,从湖州武康走了数千里到此,至少两次在这座城里落第(《再下第》"两度长安陌,空将泪见花")。带着"性孤僻寡合"的狷介、苦吟"钩章棘句"的诗学、以及奉母之命的孝子责任,他终于在半个世纪的等待后,看见自己的名字挂上了金榜。六条支流在此点燃——它们产出的不是"得意的宣泄"或"胸怀不广的轻狂",而是一个**结构性真理:人生的狂喜,只有在长期被剥夺之后,才显示其真实的重量**。"一日看尽长安花"之所以千古动人,不是因为它夸张,而是因为它**精确**——只有真正失去过近五十年的人,才知道"一日"二字的全部含义。

**关于本例**
- **系年无重大争议**:贞元十二年(796)春,孟郊进士及第之日。
- **及第年龄是模式 A 亚型的典型案例**:通行说法"四十六"在二手资料几乎 unanimity,但韩愈墓志铭原文作"年几五十",查无"四十六"对应文字。这是"后世推算值混入引文"的典型。
- **《登科后》与《再下第》押同韵部(下平六麻)**,构成内部互文——这是核查中最深的增益。
- 本例为示例。真实运行会对每一维挖得更深,并在第四阶段定稿前走第三阶段事实核查。

### 范例五(以诗论诗)——赵翼《论诗五首·其二》

> 李杜诗篇万口传,
> 至今已觉不新鲜。
> 江山代有才人出,
> 各领风骚数百年。

> **诗题校勘注**:通行本(维基文库、百度百科、古诗文网)多将"李杜诗篇"列为**其一**;部分版本及排序系统作**其二**。这种排序差异源于版本源流——《瓯北诗钞》五首全录,《瓯北集》仅录四首(无"少时学语苦难圆"一首),组诗构成与排序在两系统中本就不同。

与前几首不同:这首诗的引擎不在抒情或叙事,而在**论证**。它是一首元诗(meta-poetry)——以诗论诗,用 28 个字完成一次从诗学到历史哲学的升维。它的色温是**冷峻的明亮**——既非杜牧的愤慨,亦非苏轼的惬意,而是史学家+性灵派特有的锋利自信。

### 【世】——双层语境(诗学论争诗的特征)

**所写之世**:从李白杜甫(盛唐)到赵翼所处的清代中叶,中间隔了约千年。唐诗在乾嘉时代早已不是活的创作典范,而是被格调派奉为不可逾越的**偶像**。

**写作之世**:乾隆中后期(约 1780 年代)的乾嘉诗坛,**三派并立是这首诗的直接引擎**:

- **沈德潜格调派**:宗法汉魏盛唐,主张"温柔敦厚",以杜甫为顶点。这是清代诗坛的"复古正统"。
- **翁方纲肌理派**:以学问考据为诗之根底,偏宗宋诗。
- **袁枚性灵派**:独抒性灵,反拟古。

赵翼与袁枚同属性灵一脉,此诗正是性灵派对**格调派"荣古虐今"立场**的正面还击。它的论战对象不是抽象的"摹古之风",而是有具体派别在场的目标。

**引擎**:这不是一首"古今对照"的咏史诗,而是一首**诗学宣言**。它把唐诗从神坛上请下来,然后宣称:每个时代都必须有自己的诗人。

### 【人】——身份复合体:史学家 × 性灵派 × 探花郎

- **史学家身份**:《廿二史札记》的作者。他**习惯把任何现象放进长时段里看**——"数百年"不是诗人的夸张,而是史学家对一个文化周期的实际度量单位。这是史学家特有的时间感。
- **性灵派主将**:与袁枚同营垒,论诗主"独创",反对"荣古虐今"。这一立场赋予他**怀疑偶像的合法性**。
- **探花出身的士大夫**:乾隆二十六年(1761)殿试本拟状元,后被降为探花(一甲第三名,状元为王杰)。这是一个**自己曾被认为是"才人"、却又被权力轻轻拨开**的人。他对"才人"二字的体认,不是旁观者的赞叹,而是同处一个评价系统内部的亲历。

### 【地】——抽象化的"江山"

**(a) 诗内的空间**:"江山"二字是这首诗里最大的尺度词。但它**不是地理描写**——既不是某处具体的山河,也不是"国家政权"的代称,而是**一种抽象的空间容器**:在这片广袤的土地上,世世代代都会有人出现。"江山"配合"代",完成的是**空间×时间**的双重放大。

**(b) 诗后的地理**:这首诗没有压掉任何"路"——它本就不写路。它压掉的是**具体的人事背景**:谁在和谁争论?赵翼正在哪个书院讲席上写下此诗?这些被有意抽象掉了。这种**去具体化本身就是策略**:一首论争诗要想成为宣言,就必须把论争从具体的人事里抽离出来,上升到**关于诗的本质命题**。

### 【统】——以诗论诗的悠久谱系

- **向上**:赵翼站的是"以诗论诗"传统的脉络上——杜甫《戏为六绝句》开其端,元好问《论诗三十首》确立范式,清人王士禛、袁枚、赵翼、宋大樽等皆有论诗绝句。**赵翼此作是这条传统的清中叶节点**。
- **横向**:与同时代的论诗绝句比,赵翼的辨识度是**历史主义+性灵论的结合**。袁枚论诗偏重个体主张("但肯寻诗便有诗");赵翼把论诗从**审美主张**升级为**历史命题**——"代有才人"不是"我应该怎么写"的回答,而是"诗的历史为什么会这样运转"的回答。
- **向下**:此诗后两句已脱离原诗学语境,成为现代汉语中的**通用历史乐观主义口号**(用于政治演讲、改革宣传、教育励志)。这是接受史维度——但原诗的**论争性**几乎被遗忘了。

### 【受】——两极分化的现代挪用

| 时代 | 读法 | 出处/依据 |
|---|---|---|
| 清中后期 | 视为**性灵派论争之作**,与袁枚同调,主"独创"反"荣古虐今" | 赵翼《瓯北诗话》、袁枚《随园诗话》相互推引 |
| 现当代学术 | 视为清代诗学论争重要文献 | 现代文学史教材、主流鉴赏辞典综述 |
| 20 世纪后半叶以来 | **脱离原诗学语境,作历史乐观主义口号挪用** | "江山代有才人出"成为通用句 |
| **当下这一读** | **恢复其"诗学论争"的原语境** | 本解读提出的视角,非共识 |

**注意**:这首诗的接受史**平淡而稳定**——清中叶以来一致被读为"主独创、反摹古"。其**戏剧性在另一维度**:后两句被抽离、口号化的程度之广,使原诗的论争性几乎被遗忘。

### 【文】(枢纽)——精密的论证机器

- **炼字**:**代**(带有历史周期感的字——一代、下一代,是史学家切割历史的基本单位);**领**(主动引领,把抽象的文学史空间化、动态化);**新鲜**(反雅化的词——古典诗论通常会用"陈腐""故套",赵翼用了近乎口语的"新鲜",字面的去典雅化本身就是论点的一部分)。
- **结构**:**二铺一转一合的论证结构**。第一句立靶(承认李杜"万口传"),第二句转("已觉不新鲜"),第三句升维到历史规律("代有才人出"),第四句落回诗学完成循环论证("各领风骚")。**整首诗是一台精密的论证机器:每句都在推进论点,没有一句是装饰**。
- **声音**(按平水韵核查):七言绝句,押**下平一先**(传、鲜、年)。"觉""不""出""各""百"五个入声字散布。**听觉弧线**:首句"传"字平拖远响(万口之广);次句入声密集(已觉、不)作滞涩顿挫,模拟"新鲜感丧失"的卡顿;末句"数百年"平声拖长收束,带有"时间漫长"的余韵。**字音与论点同构**。
- **意象序列**:李杜(具体偶像·顶点)→ 万口(传播盛况)→ 新鲜(感觉判断)→ 江山(抽象空间·极大)→ 才人(抽象主体)→ 风骚(抽象成就)→ 数百年(时间度量)。**抽象层级在第二句到第三句之间骤然抬升**——从诗学到史学的跃迁。

### 六合收敛

在原点——我们无法定位一个精确的年份(通行说法 1784,**但一手史料缺位**;ctext《瓯北集》目录对应卷次标"辛丑壬寅"即 1781–1782,与通行说冲突)。但这不影响收敛——无论点火点在 1780 年代哪一年,支流都在汇聚。

在那一刻的某个书院里,一个**史学家的眼睛+性灵派主将的立场+探花郎的切身感**所汇聚成的复合体,面对乾嘉诗坛三派并立、格调派仍奉唐诗为不可逾越之偶像的格局,写下了一首**以诗论诗的宣言**。六条支流在此点燃——它们产出的不是一句现代口号,而是一个**结构性真理**:任何把过去的某个高峰奉为不可超越的偶像系统,在逻辑上都已经背叛了它声称要守护的东西(诗的本质是创造);真正的继承,不是摹仿前人的成品,而是继承前人**曾经创造**的那种创造性本身。

**关于本例**
- **系年学界无定论**:通行说法 1784 仅见于普及网站,**一手史料缺位**;ctext《瓯北集》目录对应卷次标 1781–1782,与通行说冲突。本解读采范围"约 1780–1785",明示非定论。
- **版本差异**:《瓯北诗钞》五首全录;《瓯北集》仅录四首,无"少时学语苦难圆"一首。组诗排序在两系统中不同。
- **模式 B 高发场域的典型**:赵翼是清代诗人,专门讨论此诗的学术资料稀缺。本例展示了如何在稀缺场域拒绝伪造权威和定论——不编造"钱仲联论断""学界定论"等。
- 本例为示例。真实运行会对每一维挖得更深,并在第四阶段定稿前走第三阶段事实核查。

## 核查实证——三种典型失败模式

下面是第三阶段核查最常遭遇的三种失败类型,每类配一个真实案例。**理解失败比理解成功更重要**——正向范例(杜牧、苏轼)教"怎么写对",这些反向实证教"怎么会错"。第三阶段的规则(引用分级、精确归属、稀缺度自评)就是从这些失败里提炼出来的,配着实证读才知道每条在防什么。

### 模式 A——数字偏移

**特征**:在资料丰富的主流大家身上发生。所有素材都是真的,但年份、页码、卷数这类精确数字发生小幅偏移。最容易骗过核查子代理,因为"看起来"全对。

**案例**:王维《送元二使安西》的解读中——
- 把《琴学入门》的成书年份从 **1864** 错成 **1876**(同一本书,年份偏移 12 年)
- 把黄狮子案的年份从 **721** 错成 **720**(同一事件,偏移 1 年)

**为何发生**:这两条都是真实存在的素材,主代理只是把数字记错了。核查子代理若不专门去查证这一数字,也会"看起来没问题"就放行。

**规则对应**:这类进入"色温校准依据"或"系年主张"的数字都属于 **L1 支撑性引用**,必须附 URL 到精确位置(中华书局点校本、ctext.org 等可稳定核查源),避开转述多次的二手网页。**URL 指向真书不够——必须能从 URL 直接定位到具体卷次/页码**。

**亚型——后世推算值混入引文(更隐蔽的模式 A)**:

除了"同一数字的小幅偏移"(1876→1864),还有一种更难抓的亚型:**后世推算值被当成原始引文传播**。

**案例**:孟郊《登科后》的及第年龄——
- 通行说法(百科、教材、赏析)几乎一致写"孟郊年四十六乃登进士第"
- 但韩愈《贞曜先生墓志铭》原文对应的措辞是"**年几五十,始以尊夫人之命,来集京师,从进士试**"
- "四十六"是后世按 751 生年推算的结果,**墓志铭里根本没有"四十六"这个数字**
- 它在数学上自洽(751+46≈796),在二手资料里 unanimity,但**在一手史料里查无对应文字**

**为何比纯数字偏移更危险**:
- 所有二手资料都说"四十六",若只查二手源就会"通过"
- "四十六"本身在数学上自洽,不像 1876→1864 那种"看起来就有点不对"
- 只有一手史料能证伪

**规则对应**:L1 数字主张若在一手史料中找不到对应文字,必须标注"通行说法,未见一手史料对应原文",并并列陈述一手史料的实际措辞。这是"精确归属"在数字主张上的延伸:**URL 指向真书不够,必须能从 URL 定位到该数字的实际出处段落;若定位不到,该数字就是无根的**。

### 模式 B——资料稀缺场域的共谋幻觉

**特征**:在资料稀少的主题上发生(冷门诗人、组诗系年争议大、特定地域性研究)。表现为**伪造权威/伪造谱系/伪造定论**——LLM 默认倾向是装作有扎实依据,而不是承认资料稀缺。

**案例**:赵翼《论诗五首·其二》("李杜诗篇万口传")的解读中,至少 5 处错误,典型模式包括——
- **伪造权威**:引用"钱仲联"的论断,但钱仲联并未专门讨论过这一主题——名字是真的、学者是真的、论断是编的
- **伪造谱系**:声称存在"刘勰→张若虚"的传承关系——两位都是真的、各自也是真的、关系是编的
- **过度精确**:把本有争议的系年说成"1784 年学界定论"
- **反向定义**:用"非 X 非 Y"的措辞回避正面陈述(因为正面陈述需要证据,反向定义可以糊弄过去)

**为何发生**:这是 LLM 在稀缺场域最危险的失败。更棘手的是——**核查的子代理和主代理是同一 LLM,在稀缺主题上同样会幻觉**。主代理编了一个"钱仲联的论断",核查子代理去"核查"时也可能编出同一个论断,然后"核查通过"。这是"共谋幻觉"——两个 LLM 用同一套训练数据互相背书。

**规则对应**:这类主题三个稀缺度信号(主流辞典专条、独立维基词条、学界系年共识)往往都缺。判定为"稀少"后,**降级为"假说"措辞**,禁用"学界定论""已成为共识""确证"等词——把"装扎实"的本能堵死,逼回诚实措辞。

**另一种模式 B——主流大家身上的结构性争议被压成定论**:

赵翼是"冷门诗人"诱发的模式 B,但还有一种更具欺骗性的变体——**主流大家身上也有结构性争议,但因为诗人太出名,LLM 倾向于把通行读法当定论**。

**案例**:元稹《离思五首·其四》("曾经沧海难为水,除却巫山不是云")的系年与情感归属——
- 元稹是中唐主流大家,这首诗家喻户晓,网络资料铺天盖地
- 通行读法(百科、教材、主流鉴赏辞典):**悼亡韦丛之作**,系元和四年(809)
- 但**陈寅恪《元白诗笺证稿》第四章附录"读莺莺传"明确提出异说**:此诗实为追忆早年所恋寒族女子崔莺莺(双文)而作,系年应前推
- 两说并立,**学界无共识**;但大众资料几乎只传悼亡说

**为何比赵翼案例更危险**:
- 赵翼案例的伪造(钱仲联论断)容易被识破,因为钱仲联确实没写过这主题
- 但元稹这首诗的悼亡说是"真的通行说法",若只查大众源就会"通过"——必须深入到学术文献(陈寅恪专著)才能发现争议
- 三个稀缺度信号里,前两个(辞典专条、独立维基)都是 ✓,只有"系年学界共识"是 ✗——**整体判"中等"会掩盖这个关键稀缺点**。这正说明稀缺度判定不能只看整体:整体丰富,但关键 L1 主张(系年/归属)稀少时,该条主张单独降级为假说措辞

**规则对应**:这是"系年有 2+ 候选但无共识"的典型场域——列全悼亡/赠莺莺两候选,标主流倾向(悼亡说组诗内部证据更强)但明示非定论。**组诗内部证据支持某说 ≠ 排他性证明**:其一"晓镜残妆"、其二"梳头"等闺阁细节兼容悼亡,但同样兼容赠妓——内部证据增强倾向,不构成定论。

**深化的增益**:这个案例还揭示了一个结构性洞察——**两种读法未必互斥**。若"曾经沧海"确实写给早年莺莺,而悼亡韦丛时重写或旧句新用,那么"半缘修道半缘君"的"君"字就同时承载了两段至情。这不是需要消除的歧义,而是诗最丰厚的读法。修正往往深化,不只是纠正。

### 模式 C——真实素材的错误组装

**特征**:在资料中等的主题上发生(有研究但不海量)。素材都是真的、URL 也是真的,但**该素材不属于该上下文**——把真东西放错了位置。这是最阴险的失败模式,因为 URL 指向真书,核查子代理若不熟该领域,会认为"有 URL = 已核查"。

**案例**:王勃《送杜少府之任蜀州》的解读中,至少 5 处错误,典型模式包括——
- **篇名张冠李戴**:声称闻一多在《唐诗大系》中讨论过此诗——闻一多是真的、《唐诗大系》是真的、闻一多研究初唐也是真的,但闻一多并**没有**在这本书里讨论这首诗(把真学者+真书+假主题组装成看似权威的引证)
- **时间错位**:把《檄英王鸡》的系年在 668/669 之间错位——两个年份都是真的(王勃生平中真实的年份),但事件归属到哪一年是错的
- **校勘混入原文**:把《华阳国志》里的"万里津"当作原文引用,但"万里津"实际上是**杨慎的校勘**混入正文,并非《华阳国志》原文——这是把后人校勘当原文引,等于伪造证据

**为何发生**:模式 C 的诱因是 LLM 在中等资料密度下的"完成欲"——素材都在手边,但具体归属关系查不精确,LLM 倾向于**拼出一个看似合理的组装**而不是承认查不到精确归属。这比模式 B 更难抓——因为 URL 是真的。

**规则对应**:L1 引用除 URL 外,还必须**归属到精确篇名/章节、绑定到精确记载来源、原文与校勘显式区分**。"据《xx书》记载"(无卷次)、"出自《xx集》"(无篇名)、"古人云"(无具体人)这类措辞直接触发警惕——必须降级 L2 或删。

### 三种模式的第一性原理

失败严重度与主题资料密度呈**倒 U 型**关系——这是规则设计的理论基础:

```
资料密度:    稀少  ────►  中等  ────►  丰富
失败模式:    模式 B        模式 C        模式 A
             (编造)       (错配)       (偏移)
```

- **资料太稀缺 → 编造**(模式 B):查不到就编权威、编谱系、编定论
- **资料中等 → 错配**(模式 C):素材都有,但归属关系查不精确,就乱组装
- **资料丰富 → 偏移**(模式 A):素材太多了,数字记错

这意味着:**不存在"一刀切"的防幻觉规则**。分级制度(L1/L2/L3)、稀缺度自评、精确归属要求,三者各自针对不同的失败模式,缺一不可。这也是 SKILL.md 不走"优雅降级"路线的原因——本方法定位是"为历史名篇服务",所有加固都是结构性加固,不是降级机制。
