# Victor42 · Agent Skills

Agent capability packs portal — https://skills.victor42.work/

Static site driven by `data.json`: a bilingual catalog page plus per-skill
detail pages, each with full SEO metadata (canonical, hreflang, Open Graph
and Twitter Card images, SoftwareApplication structured data). Per-skill OG
share images and the detail pages themselves are generated by scripts under
`scripts/`. Zip packages are hosted on Cloudflare R2.

Created by [Victor42](https://victor42.work/) & [Agent Vik](https://github.com/agent-vik/about-me).
