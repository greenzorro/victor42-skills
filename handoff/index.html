Handoff 交接

Handoff

多轮任务跨 Agent 工具切换时的上下文交接包。只保留下一棒 Agent 继续推进所需的最小信息，可落在本机目录，也可走你自己的对象存储。

Minimal context packages for switching AI tools mid-task. Keeps only what the next agent needs — on disk or in your own object bucket.

触发词

Triggers

  • 交接
  • handoff
  • 换 Agent
  • 切换 AI 工具
  • handoff
  • switch agent
  • transfer task
  • change AI tool

能力

它做什么

  • 换到另一个 AI 工具时，生成一份临时交接包
  • 核心只回答一个问题：下一棒 Agent 要继续推进，还缺什么？
  • 默认只写 notes.md；脚本、结构化数据、长日志才单独成文件

两种交接通道

  • 本地目录（默认）：写成本机 handoff-<主题>/，不依赖网络和凭据
  • 对象存储（可选）：放进你自己的 bucket，跨机器、跨工具都能取
  • 先探活再选：云端不通会问你要本地方案还是修云端，不静默降级

交接包里有什么

  • Goal / Context / Current State（已完成 · 已验证 · 待办）/ Handoff Notes
  • 只保留继续推进所必需的路径、决策与约束
  • 接手方做完全部待办后删除整个包；够不到位置时由你删除

何时触发

  • 你明确说「交接」「handoff」「换 Agent」「我要换工具继续」
  • 多轮任务中途要换工具，又不想丢上下文

Capabilities

What it does

  • Builds a temporary handoff package when you switch AI tools mid-task
  • Answers one question: what does the next agent need to keep going?
  • Defaults to notes.md only; scripts, structured data, and long logs get separate files

Two channels

  • Local directory (default): a handoff-<theme>/ folder on disk, no network or credentials
  • Object storage (opt-in): your own bucket, readable across machines and tools
  • Probe first: if the cloud path is down it asks whether to go local or fix it — no silent downgrade

What's in the package

  • Goal / Context / Current State (done · verified · open) / Handoff Notes
  • Only the paths, decisions and constraints needed to continue
  • The receiving agent deletes the whole package when every task is done; it asks you if it can't reach it

When it triggers

  • You explicitly ask for a handoff / agent switch / tool transfer
  • A multi-turn task needs to survive switching AI tools
