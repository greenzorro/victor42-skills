Handoff 交接

Handoff

多轮任务跨 Agent 工具切换时的上下文交接包。只保留下一棒 Agent 继续推进所需的最小信息。

Minimal context packages for switching AI tools mid-task. Keeps only what the next agent needs to continue.

触发词

Triggers

  • 交接
  • handoff
  • 换 Agent
  • 切换 Claude/GPT/Cursor
  • handoff
  • switch agent
  • transfer task
  • change AI tool

能力

它做什么

  • 在你换 Cursor / Claude / GPT 等工具时，生成一份临时交接包
  • 核心只回答一个问题：下一棒 Agent 要继续推进，还缺什么？
  • 默认只写 notes.md；脚本、结构化数据、长日志才单独成文件

交接包包含什么

  • Goal：当前要完成什么、完成标准
  • Progress：已完成 / 进行中 / 未开始
  • Next steps：下一棒该立刻做的事
  • 关键路径、决策与约束：仅保留继续推进所必需的

何时触发

  • 你明确说「交接」「handoff」「换 Agent」「我要换工具继续」
  • 多轮任务中途要换工具，又不想丢上下文

Capabilities

What it does

  • Builds a temporary handoff package when you switch AI tools mid-task
  • Answers one question: what does the next agent need to keep going?
  • Defaults to notes.md only; scripts, structured data, and long logs get separate files

What's in the package

  • Goal: what to finish and the success criteria
  • Progress: done / in progress / not started
  • Next steps: what the next agent should do immediately
  • Key paths, decisions, and constraints — only what is required to continue

When it triggers

  • You explicitly ask for a handoff / agent switch / tool transfer
  • A multi-turn task needs to survive switching AI tools
