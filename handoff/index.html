Handoff

当你做到一半要换 AI 工具，它把进度、决策与下一步交接给下一棒。

When a task is half done and you switch AI tools, it hands the progress, decisions and next steps to the next agent.

触发词

Triggers

  • 交接
  • handoff
  • 换 Agent
  • 切换 AI 工具
  • handoff
  • switch agent
  • transfer task
  • change AI tool

能力

它做什么

  • 换到另一个 AI 工具时，生成一份临时交接包（通常只有一份 notes.md）
  • 只回答一个问题：下一棒要继续推进，还缺什么
  • 典型场景：任务做到一半要换工具——目标、改过哪些文件、验证过的命令、下一步与红线，一次交代清楚，不必从头复述
  • 脚本、结构化数据、长日志才单独成文件

交接包里有什么

  • Goal / Context / Current State（已完成 · 已验证 · 待办）/ Handoff Notes
  • 只保留继续推进所必需的路径、决策与约束
  • 接手方做完全部待办后删掉整个包；够不到位置时由你删

两种交接通道

  • 本地目录：开箱即用，写成本机 handoff-<主题>/，不依赖网络与凭据
  • 对象存储：一次性配好桶、token 与 config 之后，跨机器、跨工具都能取
  • 云端没配置就不问、直接本地；配置了但不通才问你选本地还是修云端，不静默降级

何时触发

  • 你明确说「交接」「handoff」「换 Agent」「我要换工具继续」
  • 多轮任务中途要换工具，又不想丢上下文
  • 你接手别人的交接包：按包内待办推进，做完负责删包

Capabilities

What it does

  • Builds a temporary handoff package (usually a single notes.md) when you switch AI tools
  • Answers one question: what does the next agent need to keep going
  • Typical case: a task half done in one tool, picked up in another — goal, files changed, commands verified, next steps and red lines stated once instead of re-explained
  • Scripts, structured data or long logs get separate files

What's in the package

  • Goal / Context / Current State (done · verified · open) / Handoff Notes
  • Only the paths, decisions and constraints needed to continue
  • The receiving agent deletes the whole package once every open item is done; you delete it if it can't reach the location

Two channels

  • Local directory: works out of the box, writes handoff-<theme>/ on this machine, no network or credentials
  • Object storage: after a one-time bucket, token and config setup, packages cross machines and tools
  • Unconfigured cloud never asks and goes local; only a configured-but-unreachable cloud asks local-or-fix — no silent downgrade

When it triggers

  • You explicitly ask for a handoff / agent switch / tool transfer
  • A multi-turn task needs to survive switching AI tools
  • You receive someone's handoff package: work its open items, then delete it
