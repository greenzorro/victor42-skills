文件图像工具包

File-Image Toolkit

CLI 工具集：图片格式转换、缩放、去重、GIF 合成、音视频转换、文件夹扁平化等批量文件操作。

CLI toolkit for format conversion, resize, dedup, GIF compose, audio/video convert, and bulk file operations.

能力

图片

  • 格式互转：jpg / png / webp / avif / gif / bmp / tiff
  • Resize：指定宽高，裁剪或填充
  • 缩放：设定最大边长，保持比例
  • 裁头像：自动检测人脸，输出圆形或方形
  • 去重：感知哈希识别相似图
  • GIF：多帧合成 / GIF 拆成帧序列

音视频

  • 音频互转：mp3 / wav / flac / aac / ogg / m4a / opus
  • 视频互转：mp4 / avi / mov / mkv / webm 等
  • 从视频提取音轨
  • 多张图片合成视频，支持交叉淡入淡出

文件管理

  • 嵌套文件夹一键扁平化
  • 按 CSV 批量重命名
  • 支持单文件与整文件夹批量处理

Capabilities

Images

  • Convert among jpg / png / webp / avif / gif / bmp / tiff
  • Resize with crop or pad modes
  • Scale by max edge while keeping aspect ratio
  • Avatar crop with face detection (circle or square)
  • Dedup via perceptual hash
  • Compose GIF from frames / explode GIF to frames

Audio & video

  • Convert audio: mp3 / wav / flac / aac / ogg / m4a / opus
  • Convert video: mp4 / avi / mov / mkv / webm, and more
  • Extract audio tracks from video
  • Images → video with optional crossfade

Files

  • Flatten nested folders in one pass
  • Batch rename from CSV
  • Works on single files or whole folders
